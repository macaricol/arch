# Linux facts, shown one at a time while the installer works (lib/ui.sh's
# facts_tick), each for as long as it takes to read: the first one here
# always first, then the others in a random order. One per line; lines
# starting with # and empty ones are skipped. Plain ASCII punctuation: the
# console fonts have no curly quotes or long dashes.
On 25 August 1991, a 21-year-old student in Helsinki, Linus Torvalds, announced a new operating system: "just a hobby, won't be big and professional".
Linux was almost called Freax. The admin of the server hosting it named the folder "linux" instead, and the name stuck.
The first Linux release, in September 1991, was about 10,000 lines of code. Today's kernel has more than 30 million.
At first, Linux's licence banned selling it. In 1992 it moved to the GNU GPL, which it still uses today.
In 1992, Andrew Tanenbaum, creator of MINIX, posted "LINUX is obsolete". Linux went on to run most of the world's computers.
Tux the penguin exists because Linus Torvalds says a little penguin nipped him at a zoo in Australia.
Since November 2017, every one of the world's 500 fastest supercomputers has run Linux.
Every Android phone runs a Linux kernel, which makes Linux the most widely used kernel on the planet.
In 2021, NASA's Ingenuity helicopter made the first powered flight on another planet. It ran Linux.
Git was written by Linus Torvalds in 2005, in about two weeks, to manage the Linux kernel's code.
A new version of the Linux kernel comes out roughly every nine or ten weeks.
Most of the code in the Linux kernel is written by people paid by companies such as Intel, Red Hat, Google, AMD and Meta.
In Linux, almost everything is a file: your disks, your keyboard and even your processor's details appear as files.
Linux 3.11 was nicknamed "Linux for Workgroups", a nod to Windows 3.11 for Workgroups.
Linux version numbers are mostly arbitrary: Torvalds moves to a new major number when the minor one gets too big to count on fingers and toes.
The kernel's golden rule is "don't break userspace": an update must never break programs that already work.
Linux servers can get security fixes while running, without a restart, thanks to live patching.
On a frozen Linux system, holding Alt+SysRq and typing R, E, I, S, U, B restarts it safely: "Reboot Even If System Utterly Broken".
When a Linux system runs out of memory, the "OOM killer" picks a program to close so that everything else survives.
Linux runs on more kinds of processors than any other mainstream operating system, from watches and routers to mainframes.
Many cars run Linux: Automotive Grade Linux powers the dashboards of vehicles from Toyota, Subaru, Mazda and others.
Most of the world's web servers run Linux, and so does most of the cloud.
Windows can run a real Linux kernel, built by Microsoft itself, through the Windows Subsystem for Linux.
Slackware and Debian, both from 1993, are the oldest Linux distributions still maintained today.
Debian's releases are named after Toy Story characters, and its unstable branch is always "Sid", the kid who breaks toys.
Arch Linux's wiki is so thorough that people using other distributions rely on it too.
Linux From Scratch is a book that guides you through building a whole Linux system yourself, from source code.
In 2022, Linux 6.1 became the first version to accept code written in Rust, the first new language in the kernel's history.
Many people celebrate 25 August, the day Torvalds first announced Linux, as Linux's birthday.
KDE, the project behind the Plasma desktop you're installing, was started in 1996 by Matthias Ettrich.
Arch Linux was created by Judd Vinet, a Canadian programmer. Its first release came out on 11 March 2002.
Judd Vinet named Arch after the word's meaning of "principal" or "chief", as in "archenemy".
Arch Linux was inspired by CRUX, another small, simple distribution.
pacman, Arch's package manager, was also written by Judd Vinet, and it's where ARCHMAN gets its name and its Pac-Man.
Add "ILoveCandy" to /etc/pacman.conf, and pacman's progress bars turn into a Pac-Man eating pellets.
Arch is a rolling release: there are no versions to upgrade between. One "pacman -Syu" keeps your whole system up to date.
A new Arch installation image comes out on the first of every month, a snapshot of the packages at that moment.
The Arch User Repository (AUR) holds tens of thousands of build recipes, called PKGBUILDs, shared by Arch users.
Arch's guiding principles are simplicity, modernity, pragmatism, user centrality and versatility.
The Steam Deck's operating system, SteamOS, is based on Arch Linux. So are Manjaro and EndeavourOS.
Arch Linux dropped support for 32-bit PCs in 2017, to focus on 64-bit ones.
Since 2021, the official Arch installation image includes archinstall, a guided installer.
"I use Arch, btw" is one of the best-known jokes in the Linux world.
Arch Linux switched to systemd, the program that starts and manages the system, in 2012.
The GNU project, which wrote many of the tools a Linux system runs on, was started by Richard Stallman in 1983.
Linux 1.0 was released on 14 March 1994, two and a half years after the first announcement.
The name Tux was suggested by James Hughes, as short for "Torvalds' UniX".
In 1994, Linus Torvalds recorded himself saying "Hello, this is Linus Torvalds, and I pronounce Linux as Linux".
The sudo command, which lets you run things as administrator, dates back to around 1980.
Vim, one of the most loved text editors on Linux, was first released by Bram Moolenaar in 1991, the same year as Linux.
The render farm behind the visual effects of the movie Titanic (1997) ran on Linux.
In 2013, the laptops on the International Space Station switched from Windows XP to Debian Linux.
Chromebooks run ChromeOS, which is built on the Linux kernel.
Amazon's Kindle e-readers run Linux.
In 2019, IBM bought Red Hat, a Linux company, for 34 billion dollars.
In 2012, Linus Torvalds received the Millennium Technology Prize for creating Linux.
The Linux Foundation, founded in 2007, employs Linus Torvalds so he can work on Linux full time.
KDE's KHTML web engine was the starting point of Apple's WebKit, which in turn led to Google's Blink.
KDE Plasma 6, the version you're installing, was released in February 2024.
The Linux kernel has well over ten thousand configuration options, so it can be tuned for anything from a watch to a supercomputer.
Tux was drawn by Larry Ewing in 1996, using the GIMP, a free image editor that runs on Linux.
The GIMP began in 1995 as a student project by Spencer Kimball and Peter Mattis at the University of California, Berkeley.
Unix, the system Linux is modelled on, was created at Bell Labs in 1969 by Ken Thompson and Dennis Ritchie.
Dennis Ritchie also created the C programming language, which most of the Linux kernel is written in.
Short commands like ls, cp and mv date back to 1970s Unix, when every letter typed on a slow terminal counted.
Red Hat, one of the best-known Linux companies, was founded in 1993.
Ubuntu came out in October 2004. Its name is an African word for "humanity towards others".
Gentoo Linux, which builds everything from source code, is named after the gentoo penguin, the fastest swimming penguin.
openSUSE's mascot is a green chameleon named Geeko.
KDE's mascot is a friendly green dragon called Konqi.
The first version of KDE came out in 1998. GNOME, the other big Linux desktop, was started in 1997.
The X Window System, which drew Linux's graphics for decades, dates back to 1984 at MIT.
Wayland, the modern replacement for X that Plasma uses, began in 2008.
systemd, the program that starts and runs a modern Linux system, was created in 2010 by Lennart Poettering and Kay Sievers.
GRUB, the boot loader that starts your new system, stands for GRand Unified Bootloader.
Btrfs, the file system on your new device, was started in 2007 by Chris Mason, then at Oracle.
Btrfs can take a snapshot of your whole system in an instant, a copy you can go back to later.
Wine lets Linux run many Windows programs. Its name stands for "Wine Is Not an Emulator".
Steam has run on Linux since 2013, and Valve's Proton lets thousands of Windows games play on it.
LibreOffice, the free office suite, was started in 2010 as a fork of OpenOffice.org.
Firefox 1.0 came out in November 2004, and Firefox has run on Linux ever since.
The Apache web server, first released in 1995, helped Linux take over the internet.
Blender, the free 3D software that runs on Linux, was used to make Flow, which won the Oscar for best animated feature in 2025.
CERN, home of the Large Hadron Collider, runs its huge computing grid on Linux.
Google's servers, and the phones and Chromebooks it makes, all run on Linux.
The Raspberry Pi, a computer the size of a credit card, usually runs Linux. Tens of millions have been sold.
Greg Kroah-Hartman maintains the Linux kernel's stable versions, the ones most systems actually run.
Linus Torvalds was born in Helsinki in 1969 and has lived in Oregon, in the United States, for many years.
In a terminal, Tab completes the names of commands and files: type the first few letters and let Linux do the rest.
Forgot to run a command as administrator? "sudo !!" runs your last command again, with sudo.
Almost every command has a manual: "man ls" explains ls, and "man man" explains man.
Behind your desktop there are text consoles too: Ctrl+Alt+F3 opens one, and Ctrl+Alt+F1 brings you back.
There's a program called cowsay that draws an ASCII cow saying whatever you type.
Mistype ls as sl and, with the sl program installed, a steam locomotive drives across your terminal.
"pacman -S" installs a package: the S stands for "sync", with the package lists on the mirrors.
Arch Linux has been led by Levente Polyak since 2020, after Aaron Griffin's thirteen years in the role.
Arch Linux ARM and Arch Linux 32 are community projects that bring Arch to ARM devices and 32-bit PCs.
Arch's own packages are built from PKGBUILD files, the same simple format shared in the AUR.
KDE Connect, on your new desktop, lets your phone share files, notifications and its clipboard with your desktop.
KDE Plasma can look like almost anything: every panel, widget and colour can be changed in System Settings.
